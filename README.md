# XREAL VR Player for macOS

Отдельная версия [mpv](https://github.com/mpv-player/mpv) для **XREAL One Pro**, **Apple Silicon (arm64)** и **macOS 15+**. Запускается как обычное приложение: откройте фильм через ⌘O или перетащите файл в окно, без командной строки.

**[Скачать / Releases](https://github.com/davnozdu/mpv-xreal-vr-player/releases)** · **[GitHub Actions](https://github.com/davnozdu/mpv-xreal-vr-player/actions/workflows/xreal-macos.yml)** · **[Краткая инструкция](xreal/QUICKSTART-RU.md)**

## Что происходит автоматически

- Выбор дисплея XREAL / Nreal и полноэкранный вывод при подключении очков.
- Выбор аудиовыхода XREAL / Nreal, если macOS предоставляет устройство с таким именем.
- Full SBS на широком дисплее и Half SBS на обычном 16:9 дисплее. Если очки включены в обычный 2D-режим, выберите в меню **XREAL → Вывод: без 3D**.
- Определение формата по имени файла: Half/Full SBS, SBS/3D, VR180/VR360, Top/Bottom. Обычное видео без таких пометок показывается как **2D**: оба глаза видят весь кадр. Немаркированный Half SBS по размеру не отличить от 2D, поэтому для него формат один раз выбирается в меню **XREAL**.
- Для немаркированного 8K 2:1 файла, например **8192×4096 HEVC 60 fps**, предполагается **VR180 SBS**. Это эвристика: разрешение не доказывает проекцию. Исправление делается в меню **XREAL**, и выбор сохраняется для конкретного файла.
- Раздельное формирование вида для каждого глаза, включая отдельные чёрные поля для широкоформатных 3D-фильмов.
- Без очков — обычный вид одного глаза на экране Mac. Фильм открывается на весь экран; F / Escape / меню View переключают режим.

## Установка

Откройте **XREAL-VR-Player-arm64.dmg** и перенесите **XREAL VR Player.app** в Applications. ZIP содержит то же приложение. Bundle ID — `com.davnozdu.xreal-vr-player`; приложение может работать рядом с обычным mpv и не меняет его настройки или плеер по умолчанию.

На самих очках требуется включить **3D Mode → Full SBS** (3840×1080) или **Half SBS** (1920×1080). Плеер готовит изображение под текущий дисплей, но не переключает прошивку очков. [Официальная инструкция XREAL](https://tutorials.xreal.com/docs/glasses/one-series/osd/3d-mode/).

Начиная с 0.1.4 релизы подписываются постоянным собственным сертификатом **XREAL VR Player Code Signing** (SHA-1 `FB0E5758CDCAA00CD35A6A1029E3A071802CF114`). Это не Apple Developer ID и не notarization, поэтому при первом открытии macOS может попросить разрешить запуск в «Конфиденциальность и безопасность».

## Автообновление

Плеер раз в 6 часов (впервые через 20 секунд после запуска) проверяет последний релиз на GitHub. Новая версия скачивается в фоне, проверяется по SHA-256 и подписи и устанавливается после выхода из плеера; при следующем запуске открывается уже она. Обновление принимается только с той же подписью, что у установленного приложения. Разработческие ad-hoc сборки и приложение, запущенное прямо из DMG, не обновляются. Версию 0.1.4 нужно один раз установить вручную; ранние версии автообновления не содержат.

## VR и отслеживание головы

Поддерживаются обычные стереофильмы SBS и **equirectangular** VR180/VR360: SBS и Top/Bottom. Fisheye, cubemap, монопанорамы и MV-HEVC не поддерживаются.

У One Pro есть встроенный 3DoF, а с подключённым **XREAL Eye** — 6DoF для **Spatial Anchor**. Эти возможности работают в очках. Данная версия плеера **не получает данные позы головы** для изменения ракурса панорамы. Ракурс управляется клавишами; стереовидео показывается на виртуальном экране, без автоматического обзора как в Quest. [Спецификации XREAL](https://tutorials.xreal.com/docs/glasses/one-series/spec/), [Spatial Anchor с Eye](https://tutorials.xreal.com/docs/accessories/eye/how-to-use/6dof/).

Клавиши: **пробел** — пауза; **←/→** — перемотка; **W/A/S/D** — ракурс панорамы; **[ / ]** — угол обзора; **R** — центр; **E** — поменять глаза; **H** — состояние; **F** — полный экран. Все режимы доступны в меню **XREAL**. Субтитры и стандартный OSC отключены, поскольку их вывод не разделён между глазами.

## macOS / ARM и быстродействие

- Нативный **arm64**, сборка **Release / -O3**, **LTO**, оптимизация Swift `-O`.
- **VideoToolbox** для аппаратного декодирования, включая HEVC, если профиль и размер поддерживаются Mac.
- Декодер выдаёт кадры, совместимые только с Metal. FFmpeg по умолчанию запрашивает ещё и совместимость с OpenGL, а это замедляет аппаратный декодер в 2–2,5 раза: на M2 Pro 8K HEVC (7680×3840, 60 fps) декодируется со скоростью ~50 fps вместо ~115 fps. Исправление в `osdep/mac/vt_metal_buffers.c`.
- Для 8K/60 автоматически оцениваются пропуски кадров. Если VideoToolbox всё же не успевает при достаточной скорости GPU, плеер пробует CPU и возвращает VideoToolbox, если результат хуже. Смена выполняется максимум один раз за фильм; командная строка не нужна.
- Билинейная фильтрация снижает затраты GPU при подготовке панорамного изображения и выводе на Retina-дисплей.
- Вывод: **gpu-next + macvk**, **Vulkan через MoltenVK/Metal**, прямой импорт кадров VideoToolbox в GPU. Встроенные параметры используют поддерживаемый этой сборкой контекст macvk.
- Проекция VR180/360 — GLSL shader на GPU с результатом **3840×1080** для очков или **1920×1080** для ноутбука, без CPU-фильтра `v360` и без принудительного copy-back декодирования.
- Собственный кэш шейдеров; до 256 MiB буфера и 10 секунд опережающего чтения.
- CI проверяет архитектуру, настройки оптимизации, наличие VideoToolbox, Metal interop и `macvk`. Отчёт `optimization-audit.json` входит в приложение.

Наличие этих возможностей в сборке не гарантирует 8K60 для каждого профиля HEVC и каждой модели Mac. Аппаратное декодирование может перейти на CPU при неподдерживаемом файле. Физический вывод на XREAL и конкретный пользовательский фильм требуют проверки с очками.

## Сборка на GitHub

Workflow **XREAL macOS build** использует `macos-15` (ARM). При push в `xreal` собирает исходники, запускает тесты, упаковывает библиотеки внутрь `.app`, подписывает приложение постоянным сертификатом из секретов `XREAL_SIGNING_P12_BASE64` / `XREAL_SIGNING_P12_PASSWORD` (для тегов `xreal-v*` они обязательны), проверяет подпись и отсутствие ссылок на Homebrew, создаёт DMG/ZIP с SHA-256. Артефакты доступны в Actions. Тег `xreal-v*` создаёт публичный GitHub Release с установочными файлами.

Для локальной разработки:

```sh
brew install meson ninja pkgconf ffmpeg libass libplacebo luajit zlib bzip2 vulkan-loader molten-vk shaderc
bash xreal/build.sh
```

Пользователю установленного приложения Homebrew и терминал не нужны.
