# XREAL VR Player

1. Откройте `XREAL-VR-Player-arm64.dmg`, перенесите **XREAL VR Player.app** в Applications.
2. Запустите приложение, откройте фильм через **⌘O** или перетащите файл в окно.
3. Подключите XREAL One Pro к Mac. В меню очков выберите **3D Mode → Full SBS** для 3840×1080 или **Half SBS** для 1920×1080. Плеер выбирает дисплей XREAL и запускает полноэкранный вывод.
4. По умолчанию включён автоматический выбор формата. Если проекция определена неверно, один раз выберите формат в меню **XREAL** — выбор сохраняется для этого файла.

Для немаркированного файла 8192×4096 плеер предполагает **VR180 SBS**. Размер сам по себе не доказывает эту проекцию. Поддерживаются equirectangular VR180/360 с двумя видами рядом либо сверху/снизу. Fisheye, cubemap, MV-HEVC и монопанорамы в эту версию не входят.

**Клавиши:** пробел — пауза; ←/→ — перемотка; W/A/S/D — ракурс панорамы; [ / ] — угол обзора; R — центр; E — поменять глаза; H — состояние; F — полный экран. Прочие обычные клавиши mpv работают.

Без очков можно проверить приложение на экране Mac: две картинки рядом здесь нормальны. В очках каждый вид должен попасть в свой глаз. Если глаза перепутаны, нажмите E.

XREAL One Pro поддерживает встроенную 3DoF-стабилизацию; с XREAL Eye — 6DoF Spatial Anchor. Плеер не получает данные позы головы: обзор VR-панорамы управляется клавишами. Получается стереопросмотр в очках; автоматического обзора как в Quest эта версия не делает.

Приложение отдельно от mpv: собственный bundle ID, собственные настройки и журнал; пользовательский `~/.config/mpv` не читается. Не назначает себя плеером по умолчанию. Субтитры и стандартный OSC отключены, поскольку они не подготовлены для двух глаз.

Версия для **Apple Silicon, macOS 15 и новее**. Приложение подписано локальной ad-hoc подписью, без Apple notarization. При блокировке первого запуска используйте разрешение для этого приложения в настройках macOS → «Конфиденциальность и безопасность». Не отключайте Gatekeeper целиком.

8K HEVC 60 fps / 122 Мбит/с: доступно аппаратное декодирование VideoToolbox, преобразование панорамы выполняется на GPU. Скорость зависит от модели Mac, профиля HEVC и накопителя. На физическом XREAL и конкретном пользовательском фильме эта версия пока не проверена.
