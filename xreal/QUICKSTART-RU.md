# XREAL VR Player

1. Откройте `XREAL-VR-Player-arm64.dmg`, перенесите **XREAL VR Player.app** в Applications.
2. Запустите приложение, откройте фильм через **⌘O** или перетащите файл в окно.
3. Подключите XREAL One Pro к Mac. В меню очков выберите **3D Mode → Full SBS** для 3840×1080 или **Half SBS** для 1920×1080. Плеер выбирает дисплей XREAL и запускает полноэкранный вывод; при наличии аудиоустройства XREAL выбирает и звук в очках.
4. По умолчанию включён автоматический выбор формата. Если проекция определена неверно, один раз выберите формат в меню **XREAL** — выбор сохраняется для этого файла.

Обычное видео без пометок SBS/3D/180/360 в имени файла показывается как **2D**: оба глаза видят весь кадр. Стереофильм Half SBS без пометки в имени имеет тот же размер, что и обычное видео, поэтому для него выберите **3D · Half SBS** в меню **XREAL**. На очках 1920×1080 обычное видео показывается одной картинкой, как в обычном плеере.

Для немаркированного файла 8192×4096 плеер предполагает **VR180 SBS**. Размер сам по себе не доказывает эту проекцию. Поддерживаются equirectangular VR180/360 с двумя видами рядом либо сверху/снизу. Fisheye, cubemap, MV-HEVC и монопанорамы в эту версию не входят.

**Клавиши:** пробел — пауза; ←/→ — перемотка на 5 секунд, ↑/↓ — на минуту, шкала внизу экрана появляется при движении мыши; W/A/S/D — ракурс панорамы; [ / ] — угол обзора; R — центр; E — поменять глаза; H — состояние; F — полный экран. Прочие обычные клавиши mpv работают.

Без очков плеер показывает один вид в обычном формате 16:9 на экране Mac. Фильм открывается на весь экран; F, двойной щелчок или меню View переключают полный экран, Escape возвращает окно. При подключении очков автоматически включается SBS. Если глаза перепутаны, нажмите E.

XREAL One Pro поддерживает встроенную 3DoF-стабилизацию; с XREAL Eye — 6DoF Spatial Anchor. Плеер не получает данные позы головы: обзор VR-панорамы управляется клавишами. Получается стереопросмотр в очках; автоматического обзора как в Quest эта версия не делает.

Приложение отдельно от mpv: собственный bundle ID, собственные настройки и журнал; пользовательский `~/.config/mpv` не читается. Не назначает себя плеером по умолчанию. Шкала перемотки показывается, когда картинка не разделена на глаза. Субтитры отключены, поскольку не подготовлены для двух глаз.

Версия для **Apple Silicon, macOS 15 и новее**. Приложение подписано постоянным собственным сертификатом, без Apple notarization. При блокировке первого запуска используйте разрешение для этого приложения в настройках macOS → «Конфиденциальность и безопасность». Не отключайте Gatekeeper целиком.

8K HEVC 60 fps / 122 Мбит/с: плеер начинает с аппаратного декодирования VideoToolbox, преобразование панорамы выполняется на GPU. На M2 Pro файл 7680×3840 HEVC 60 fps декодируется со скоростью около 115 fps. При сильных пропусках кадров плеер автоматически пробует CPU и сохраняет более удачный вариант. Скорость зависит от модели Mac, профиля HEVC и накопителя. На физическом XREAL и конкретном пользовательском фильме эта версия пока не проверена.

**Обновления** устанавливаются автоматически: плеер сам проверяет GitHub, скачивает новую версию в фоне и ставит её после выхода из плеера. Принимается только версия с той же подписью. Держите приложение в «Программах», а не запускайте из DMG.
